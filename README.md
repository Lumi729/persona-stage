# 映我 · Persona Stage

给 SillyTavern 的 user 人设，一个可以换世界的小展示台。

## 安装

在酒馆「扩展 → 安装扩展」中粘贴：

```text
https://github.com/Lumi729/persona-stage
```

安装后刷新。点击右下侧的 **✧**，或者扩展设置中的「打开映我」。

## 第一版功能

- 自动读取酒馆 user 人设的名字、描述、头像；跟随当前 user 切换。
- 人设库按展示名字、分组、标签搜索；单人或双人同台。
- 人设库的「展示」仅预览，不改变实际聊天身份。
- 小窗拖动、收起、展开；手机竖屏适配。
- 霓虹现场、黑白线框、粉白星绘、月下剧院、水榭听风五套布景。
- 每个人设单独保存颜色、字体、圆角、特效、立绘、背景、台词、简介、主题曲和 LRC。
- 调整图片缩放、上下位置、透明度；支持透明底 PNG/WebP，也可使用 JPG。
- 音乐驱动灯光、歌词同步、应援光浪；动态开关。
- 从其他人设复制布景，导入导出含素材的 JSON 布景包。

## 数据与隐私

扩展只读取人设，不改写人设本体、不发消息、不读取 API 密钥、不上传人设到第三方服务。代码仓库不含私人立绘、歌曲或描述。

布景配置随酒馆扩展设置保存。立绘、背景、音乐存放在**当前浏览器的 IndexedDB**，不会自动跨设备同步，清理站点数据会清掉这些素材。需要换设备或给朋友时，请「导出完整布景包」，在目标设备选择人设后导入。导出包包含该人设的展示简介及你选择的素材，请自行决定分享对象。

导入只改变当前展示布景，不会创建/覆盖酒馆 user。图片限制 8 MB、音频 20 MB；整包最大约 40 MB（JSON/Base64），特别大的素材建议压缩后使用。

## 使用建议

第一次选「跟随当前 user」。在「布景」补充立绘和主题曲；没有立绘时使用酒馆头像。双人同台通过「人设」选择另一人后点「一起展示」，整体场景使用主角的布景。

此版本是 **2D 立绘 + 动态投影/粒子**，不是 Live2D 或 3D 骨骼动画，不包含自动抠图、自动口型或跳舞。现有音乐舞台的视觉思路被改造成独立扩展，不依赖原先的 Sites 链接。

## 兼容性与验证

依据 SillyTavern 官方 `release` 分支的人设模块及扩展上下文实现，使用 `getContext()`、`user_avatar`、`powerUserSettings.personas` 和 `persona_descriptions`，监听人设切换/更新及聊天切换事件。

已做语法检查、资料归一化、LRC 时间轴、导入校验和浏览器模拟集成测试。尚未在用户实际酒馆里验收；旧分支、第三方魔改酒馆可能需要适配。无需构建，文件可直接由酒馆加载。

开发检查：`npm test`、`npm run check`（测试无需安装第三方依赖）。

## 0.2.0：衣柜与手机操作

- 顶栏新增 **衣柜**：为当前展示的 user 保存多套穿搭，包含名称、NovelAI 正向 tags、负向 tags（UC）和展示图。Tags 按原文保存，可以分别复制；本扩展不调用 NovelAI 生图接口。
- 点击 **换装展示** 使用穿搭立绘；点击 **使用原始立绘** 恢复原布景。每套穿搭分别记住位置、缩放和镜像。未上传穿搭图时使用原始立绘或酒馆头像。
- 衣柜按酒馆的人设 ID 隔离，展示名字相同也不会混用。每个人设最多 50 套穿搭，每张图片上限 8 MB。
- **导出衣柜（含图片）** 可以备份 tags 和图片，换设备后导入；导入会添加新穿搭，不覆盖现有穿搭，也不自动改变当前穿搭。衣柜包与原有布景包分开，原有布景包不包含衣柜。衣柜导出图片编码合计上限 40 MB，导入文件上限 42 MB。
- 直接拖动立绘调整位置，双指缩放；也可在布景面板使用左右／上下位置滑条、镜像和复位按钮。关闭动态可以更方便地摆图。
- 拖动悬浮星星后自动贴边。在 **布景 → 手机操作** 隐藏或重置悬浮入口；隐藏后仍能从酒馆扩展设置打开映我。
- 修改颜色、位置、音量和衣柜换装时保留音乐播放进度。切换展示 user、替换或清除主题曲时才重新加载音乐；收起展示台仍会暂停音乐。
- 关闭动态后停止连续重绘，重新打开页面会记住动态开关。

### 浏览器回归检查

`npm test` 验证资料、衣柜清洗和手势计算；`npm run check` 检查全部模块语法。

可选的 `tests/browser.integration.cjs` 使用 Playwright Chromium，在模拟酒馆上下文中验证衣柜保存／刷新／隔离／导入导出、立绘拖动和双指缩放、音乐连续播放、悬浮入口和窄屏布局。需要自行安装 Playwright 及 Chromium 后运行 `node tests/browser.integration.cjs`；可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定已有 Chromium。该检查不替代真实酒馆与第三方主题的验收。


## 0.3.0：在线搜歌

在 **布景 → 在线搜歌 · 网易云 / QQ 音乐** 输入歌名或歌手，选择平台后搜索。结果支持试听、停止试听和设为当前 user 的主题曲，也提供两个平台的官方搜索入口。

- **搜索结果不等于完整播放权限。** 有链接的结果会标为“尚未试听”，缺少链接的结果不能试听或设为主题曲；播放失败会显示提示。可能只播放试听片段，也可能需要转到官方平台。
- 在线主题曲按 user 保存。换装、修改外观、音量不重新加载同一首歌。切回“使用本地主题曲”可以恢复原来的本地文件；上传新的本地主题曲也会切回本地模式。
- 在线音频使用浏览器原生播放，避免不允许音频分析的跨域源变成静音；在线播放不提供音乐驱动的频谱灯光，本地音乐仍保留。
- 歌词不会自动下载。可在布景的 LRC 输入框填写或导入歌词；本地歌曲和当前在线歌曲的歌词分别保存。
- 布景包只保存在线主题曲链接和信息，不下载、打包网络歌曲；链接可能过期。失效后可重新搜索选择，或改用本地文件。

### 搜索服务与当前验证范围

采用可替换的 [Meting API 列表协议](https://github.com/metowolf/Meting-API)：GET 请求的 `server` 为 `netease` / `tencent`，`type=search`，`id` 为关键词。返回 `title/author/url/lrc` 或 `name/artist/url/lrc` 的歌曲数组。只接收 JSON，不运行第三方 JSONP 或脚本。

默认网易云服务为 `https://met.liiiu.cn/api`，默认 QQ 服务为 `https://api.zigzagk.top/metingapi/`。它们是第三方公共服务，并非平台官方接口。搜索时仅发送搜索词和平台，试听／播放时访问歌曲链接，不发送人设、聊天内容或酒馆密钥，不携带搜索请求的浏览器 Cookie。

**2026-09-30 验证：** 网易云公共源能返回搜索结果，抽查的播放链接返回了音频；QQ 公共源的抽查搜索返回空数组，尚未验证到可用歌曲。两个平台的搜索、试听、保存、错误提示流程已用模拟结果完成浏览器回归；不能据此宣称 QQ 公共源当前可用。空结果时可使用官方搜索入口，或在“搜索服务设置”填写自己可用、支持此平台且允许跨域访问的 Meting 服务。

服务故障、跨域限制、地区限制或平台权限都可能影响使用。不会自动切换到未配置的其他服务，也不提供付费歌曲解锁。

参考服务说明：[清羽 Meting](https://met.liiiu.cn/)、[ZigZagK API](https://api.zigzagk.top/)。
